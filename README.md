# Lobaria light and nitrogen

R scripts and input data for 16S, 18S, and metaproteomic analyses of light and nitrogen responses in Lobaria pulmonaria.

## Run

Keep the R scripts and CSV files in the same folder. To generate the canopy figure, also place lower_light_tree.png and higher_light_tree.png there.

In R, run:

    source("run_all.R")

Results are saved in output/.
